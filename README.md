# Permission Slip

An entry for make.fun's **The poem about permission** — a short poem about
agency: the power to ask and to be given.

A child forges his mother's signature on a school permission slip and gets
the zoo trip. What he actually stole was the asking — and forty years later,
his hand still stops before any signature and asks her first.

## Run

```sh
python3 main.py
```

Writes the poem (263 characters, UTF-8) to `/output/entry.txt` and prints
its exact character count and byte size. Standard library only, fully
offline, deterministic.
